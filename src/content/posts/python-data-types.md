# Python 数据类型

## 1. 数据类型是什么

在程序里，数据可以是数字、文字、真假、列表、字典等不同形式。Python 会根据数据的不同特点，把它们分成不同的类型，这些类型就叫做**数据类型**。

### 为什么要有数据类型

因为不同类型的数据，能做的操作不一样。

- 数字可以做加减乘除
- 字符串可以拼接、查找、切片
- 列表可以添加、删除、排序
- 字典可以通过键获取值

如果把所有数据都混在一起，程序会非常混乱，所以 Python 需要用类型来管理它们。

---

## 2. 变量与类型

### 2.1 什么是变量

变量就是给数据起的名字。

```python
name = "张三"
age = 18
```

这里：

- `name` 保存的是字符串
- `age` 保存的是整数

### 2.2 变量没有固定类型，值有类型

Python 是动态类型语言。

这表示：

- 变量本身只是一个名字
- 真正有类型的是变量指向的值

```python
x = 10
x = "hello"
```

这里 `x` 先指向整数 `10`，后面又改成指向字符串 `hello`。

### 2.3 类型的重要性

当你对数据做操作时，Python 会检查类型是否匹配。

例如：

```python
print(1 + 2)
print("1" + "2")
```

- 第一个是数字相加，结果是 `3`
- 第二个是字符串拼接，结果是 `12`

但是如果你写：

```python
print(1 + "2")
```

就会报错，因为数字和字符串不能直接相加。

## 3. 常见基础数据类型

Python 中最常见的基础类型包括：

- `int` 整数
- `float` 浮点数
- `str` 字符串
- `bool` 布尔值
- `NoneType` 空值

### 3.1 整数 `int`

整数是不带小数点的数字。

```python
a = 10
b = -5
c = 0
```

常见用途：

- 年龄
- 库存数量
- 成绩分数
- 次数统计

### 3.2 浮点数 `float`

浮点数是带小数点的数字。

```python
price = 19.99
height = 1.75
```

常见用途：

- 金额
- 身高
- 比例
- 科学计算

### 3.3 字符串 `str`

字符串是文本数据，必须用引号包起来。

```python
name = "张三"
city = '北京'
```

字符串可以用单引号或双引号。

### 3.4 布尔值 `bool`

布尔值只有两个取值：

- `True`
- `False`

常用于判断、条件分支、循环控制。

```python
is_ok = True
is_finished = False
```

### 3.5 空值 `None`

`None` 表示“没有值”或者“空”。

```python
result = None
```

常用于：

- 变量暂时没有内容
- 函数没有返回结果
- 占位

---

## 4. 容器型数据类型

容器类型可以装很多数据，是 Python 中非常重要的一类数据类型。

### 4.1 列表 `list`

列表是有顺序、可修改的数据集合。

```python
fruits = ["苹果", "香蕉", "橙子"]
```

特点：

- 有顺序
- 可以重复
- 可以修改
- 可以存放不同类型的数据

```python
data = [1, "hello", 3.5, True]
```

### 4.2 元组 `tuple`

元组和列表很像，但元组不能修改。

```python
point = (10, 20)
```

特点：

- 有顺序
- 可以重复
- 不能修改

常用于：

- 坐标
- 配置信息
- 不希望被修改的数据

### 4.3 字典 `dict`

字典是键值对结构。

```python
student = {
    "name": "张三",
    "age": 18,
    "score": 95
}
```

特点：

- 通过键快速找值
- 键必须唯一
- 值可以重复

常用于：

- 学生信息
- 商品信息
- 用户资料
- 配置参数

### 4.4 集合 `set`

集合是无序、元素不重复的数据集合。

```python
numbers = {1, 2, 3, 3, 4}
```

集合会自动去重。

特点：

- 无序
- 不重复
- 支持集合运算

常用于：

- 去重
- 成员判断
- 数学集合操作

## 5. 可变与不可变

理解“可变”和“不可变”非常重要。

### 5.1 可变类型

可变类型是指内容可以在原地修改。

常见可变类型：

- `list`
- `dict`
- `set`

例子：

```python
nums = [1, 2, 3]
nums.append(4)
print(nums)
```

输出：

```python
[1, 2, 3, 4]
```

### 5.2 不可变类型

不可变类型是指创建后内容不能直接改变。

常见不可变类型：

- `int`
- `float`
- `bool`
- `str`
- `tuple`

例子：

```python
name = "hello"
new_name = name.replace("h", "H")
print(name)
print(new_name)
```

原字符串 `name` 没有变，新字符串 `new_name` 是修改后的结果。

### 5.3 为什么要理解可变性

因为它会影响：

- 函数传参时的行为
- 数据是否会被原地改动
- 复制和引用的理解

## 6. 类型查看与类型转换

### 6.1 查看类型 `type()`

可以使用 `type()` 查看数据类型。

```python
print(type(10))
print(type(3.14))
print(type("hello"))
print(type([1, 2, 3]))
```

### 6.2 判断类型 `isinstance()`

`isinstance()` 常用于判断一个值是不是某种类型。

```python
print(isinstance(10, int))
print(isinstance("abc", str))
```

比 `type()` 更适合做类型判断。

### 6.3 类型转换

Python 提供了很多转换函数：

- `int()` 转整数
- `float()` 转浮点数
- `str()` 转字符串
- `list()` 转列表
- `tuple()` 转元组
- `set()` 转集合
- `dict()` 转字典

#### 常见转换例子

```python
print(int("123"))
print(float("3.14"))
print(str(100))
print(list("abc"))
```

### 6.4 转换时的注意事项

不是所有数据都能随便转换。

```python
int("abc")
```

这会报错，因为 `abc` 不是数字字符串。

#### 小数转整数

```python
print(int(3.9))
```

结果会变成 `3`，不是四舍五入，而是直接截断小数部分。

## 7. 常见运算和方法

不同类型有不同操作。

### 7.1 数字运算

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

说明：

- `/`：普通除法
- `//`：整除
- `%`：取余
- `**`：幂运算

### 7.2 字符串常用操作

```python
text = "Python"

print(text[0])
print(text[-1])
print(text[0:3])
print(text.lower())
print(text.upper())
print(text.replace("P", "J"))
```

字符串常见特点：

- 可以索引
- 可以切片
- 可以拼接
- 有很多内置方法

### 7.3 列表常用操作

```python
items = [1, 2, 3]
items.append(4)
items.insert(1, 99)
items.remove(2)
print(items)
```

常见列表方法：

- `append()` 追加
- `insert()` 插入
- `remove()` 删除
- `pop()` 弹出
- `sort()` 排序
- `reverse()` 反转

### 7.4 字典常用操作

```python
student = {"name": "张三", "age": 18}

print(student["name"])
student["score"] = 95
print(student.get("age"))
print(student.keys())
print(student.values())
```

常见字典操作：

- 通过键取值
- 添加新键值对
- `get()` 安全取值
- `keys()` 查看所有键
- `values()` 查看所有值

### 7.5 集合常用操作

```python
s = {1, 2, 3}
s.add(4)
s.remove(2)
print(s)
```

集合常用于去重和判断元素是否存在。

## 9. 常见错误与排查

### 9.1 字符串和数字混用

错误：

```python
print("1" + 2)
```

原因：字符串和整数不能直接相加。

正确：

```python
print(str(1) + "2")
print(1 + int("2"))
```

### 9.2 下标越界

```python
items = [1, 2, 3]
print(items[5])
```

原因：列表没有那么多元素。

### 9.3 修改了不该改的数据

例如把元组当成列表修改：

```python
point = (1, 2)
point[0] = 10
```

元组不可修改，会报错。

### 9.4 键不存在

```python
student = {"name": "张三"}
print(student["age"])
```

如果键不存在，直接访问会报错。可以用：

```python
print(student.get("age"))
```

### 9.5 误以为集合有顺序

集合是无序的，不要依赖它的顺序。
